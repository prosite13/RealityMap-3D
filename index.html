촬영한 사진을 바탕으로 복원 작업을 준비합니다.

사진을 최소 20~30장 이상, 서로 겹치도록 촬영하는 것을 권장합니다.
정직한 기능 안내: 현재 웹 버전에는 SfM/깊이 추정/3D Gaussian Splatting 복원 엔진이 아직 탑재되지 않았습니다. 이 버튼은 사진 세트와 복원 작업 정보를 준비하지만, 실제 3D 모델을 생성했다고 표시하지 않습니다. 실제 복원은 Android 네이티브 엔진 연결 후 가능합니다.
실제 깊이 스캔 결과

AR Depth API에서 읽은 깊이값과 카메라 위치를 결합한 점군입니다. 촬영 커버리지 표시와는 별개인 실제 공간 좌표입니다.

아직 생성된 3D 점군이 없습니다.
촬영 커버리지와 3D 복원은 다릅니다

커버리지 맵은 촬영 방향 기록입니다. 위 점군 뷰어는 WebXR Depth API가 실제로 반환한 깊이값이 있을 때만 생성됩니다.

사진과 프로젝트는 이 브라우저의 기기에 저장됩니다. 카메라는 HTTPS 권한이 필요합니다.
